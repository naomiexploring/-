# 代理人 FAQ（简明版）

> 针对客户互动活动（生日加保、首周年检视、新客体验、都会尊享、儿童 H5 礼遇、高加保潜力标签）的常见问题。答案基于活动运营实际回复与系统规则。

## 1. 入口与操作
**Q：活动入口在哪里？**
A：进入 `iAgent` 首页 → `Care Plus` → `CarePlus 客户名单`，默认自动进入“关爱”页签。在名单中可查看“AI成长礼遇”与“孩子开学礼遇”等分组。建议优先筛选高加保潜力客户，结合系统自动生成的话题与兴趣标签寻找沟通切入点，点击“去互动”生成专属海报并转发给客户进行破冰。

**Q：海报怎么生成、怎么发给客户？**
A：在关爱名单里找到客户 → 生成互动海报 → 点"保存 & 微信"转发。如遇 iOS 转发图片异常，可改用"复制链接"发给客户。

**Q：点客户头像/姓名能跳到客户 360 吗？**
A：正常情况下可以。若提示"显示我不是代理人"等异常，请截图反馈（属已知 bug，IT 在修）。

## 2. 资格与名单
**Q：哪些客户符合条件？为什么我名单是 0？**
A：系统按活动规则（如生日月、VIP 等级、首周年等）自动圈定。新人/小单客户暂时为 0 属正常——先拓新客、做基础礼遇，名单会随客户积累增长。

**Q：名单里同一个客户出现两次？**
A：若客户名下有多个被保人（如两个孩子跨页），会显示为多张客户卡，属正常展示。

**Q：VIP / 尊悦会要哪一档才参加？**
A：各活动门槛不同，详见活动规则长图；尊悦会等级也是你判断加保时点的抓手。

## 3. 规则与机制
**Q：为什么有的生日贺卡有抽奖二维码、有的没有？**
A：已经抽过奖的客户，贺卡不再带二维码。可进入 `iAgent` 首页 `CarePlus 客户名单` 的生日专区查询抽奖记录。

**Q：互动问题 / 抽奖能改选吗？**
A：H5 互动问题提交后不可改选，客户再次进入会跳过、直达服务推荐页。

**Q：截止日期怎么算？**
A：如宝宝生日礼遇，截止日应为宝宝生日所在月的最后一天；若显示异常请反馈。

## 4. 物料与转发
**Q：海报图片下载不出来 / 全白 / 转发失败？**
A：多为 iOS 端加载问题，IT 已优化转发功能；临时可用"复制链接"替代。仍异常请反馈机型与系统版本。

**Q：能自己改图文、或改打电话 / 手写卡吗？**
A：可以。公司模板是基础，温情派代理人常按客户喜好二次编辑；对不习惯线上的客户，电话/手写卡同样有效。

## 5. 客户体验与领取
**Q：客户怎么领？我这边能看到吗？**
A：客户通过你发的海报进 H5 领取；领取后你的"客户动态"会实时同步。

**Q：能不能我代客户领？**
A：建议先跟客户打招呼再代操作，避免客户察觉"已被代领"造成尴尬（代领需客户证件号后四位等验证）。

**Q：有孩家庭客户怎么领取礼遇？**
A：主要有两种领取方式：
1. 公司主动推送：通过邮件和微信服务通知向客户发送专属 H5 链接。
2. 代理人转发海报（推荐）：在 `iAgent` 首页进入 `CarePlus 客户名单` → 关爱名单 → 找到客户并点击"去互动" → 生成专属海报并保存，通过微信转发给客户，客户扫码校验身份后即可领取。
注意事项：以宝宝生日礼遇为例，需在宝宝生日当月最后一天前领取，领取后 30 天内必须激活。若已领未激活，海报标题会变为"立即激活"以便提醒；多个被保人可分别领取。建议在生日前月、当月、次月的黄金窗口期跟进。

## 6. 系统问题与反馈
**Q：活动会不会又卡顿 / 崩溃？**
A：上线前已做生产验证；如仍遇卡顿、报错，请记录机型/系统版本/截图反馈至指定对接人，IT 按进度修复。

**Q：出问题找谁、多久回？**
A：统一反馈给活动运营对接人（如 Greta），一般当日响应；重大 bug 同步 IT 排期。

## 7. 价值与适配
**Q：这活动能帮我签单吗？**
A：活动本身是"售后接触理由"，不是直接促单。生日/周年/尊享是自然的加保沟通窗口；高加保潜力标签可辅助锁定时机。

**Q：大客户看不上小恩小惠怎么办？**
A：对高净值客户，用"都会尊享"权益（体检、私人医生等）替代积分小礼，匹配其身份感。

**Q：我客户少 / 都是小单，参与门槛高？**
A：先做基础礼遇与新人体验计划积累信任；门槛高的尊享活动随客户成长再参与，不必焦虑。
