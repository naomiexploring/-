## 一、活动概览

Care Plus 2.0 是公司面向「有孩家庭」这一核心客群推出的持续性经营项目。项目依托 **iAgent-Care Plus 平台**，为代理人提供**精准的客户名单**、**创新的互动工具**以及**深度的客户洞察**，全面赋能大家把握商机。

- **目标客群**：已为孩子购买保单、且孩子处于不同成长阶段的「有孩家庭」投保人。
- **核心抓手**：围绕孩子成长的每一个关键节点，定制专属礼遇，用专业与温度深化客户信任。
- **两大价值**：① 对客户——在陪伴孩子成长的每个重要时刻都能感受到大都会人寿的关怀；② 对代理人——通过送礼遇自然收集经营线索，结合客户关心的话题开展 NBS（需求导向销售），事半功倍。

## 二、为什么是"有孩家庭"？（数据洞察）

「有孩家庭」不仅互动积极，更是名副其实的高价值客群（数据来源：渠道整体对比）：

| 指标 | 有孩家庭 | 渠道整体 |
|---|---|---|
| 人均保单持有量 | **3.7 张** | 2.5 张 |
| AFYP 2 万以上高净值客户占比 | **31%** | 19% |

**关键判断**：
- 有孩家庭已为孩子购买保单，保障意识强。
- 随着孩子的成长，家庭需求是**动态生长、不断迭代**的（健康 → 陪伴 → 教育 → 心理 → 财务规划）。
- 抓住了孩子成长的每一个关键节点，就等于抓住了家庭保障规划的核心切入点，背后蕴藏着巨大的转化潜力。

## 四、经营方法论：两步闭环

整个有孩家庭持续经营遵循一个清晰的双步骤闭环：

```
① 送礼遇 + 收集经营线索
        ↓
   客户在 H5 互动中表达需求 → 系统生成「话题标签」
        ↓
② 跟进客户关心的话题 + NBS（需求导向销售）
```

> **核心理念**：每一个精心策划的活动、每一次真诚的互动，都是传递大都会人寿专属关怀、深化客户信任的绝佳机会。先进行「送礼遇」温暖破冰，再结合客户关心的话题开展 NBS，必将事半功倍。

## 五、活动一：宝宝生日礼遇（进行中 · 重点）

### 5.1 客户体验设计

**场景还原**：晚上 8 点，一位宝妈哄睡宝宝后收到消息："大都会人寿为您提前送来宝宝生日祝福和儿科医生服务，请领取礼遇。"点开链接，是一个精心设计的互动页面——看着宝宝成长的里程碑，宝妈惊喜地发现页面还能连线儿科医生解答育儿困惑。在互动中，宝妈为宝宝选择生日礼物，并顺手记下 VIP 全球礼宾服务的咨询选项。

> 自 2025 年 6 月起，每一位 **1-3 周岁宝宝**的投保人，都将在宝宝生日前夕收到专属推送，受邀领取儿科电话医生服务。**100% 有礼，即领即享。**

**三大体验亮点**：

**亮点 1：每一个宝宝都有专属页面（量身定制）**
成长不可复制，H5 页面内容与宝宝不同成长阶段呼应：

- **1 岁宝宝**——"宇宙级小可爱"：开始尝试自主进食、探索世界。
- **2 岁宝宝**——"动手能力 MAX 的乖乖"：手里紧紧抱着小兔子玩偶，精准捕捉 2 岁幼儿对安抚物产生依恋、建立安全感的心理特征。
- **3 岁宝宝**——"色彩小达人"：契合学龄前儿童空间想象力与创造力爆发的关键期。

**亮点 2：认真回应「每一位父母的期待」（需求探测雷达）**
互动界面提问"你最想为宝宝送上的生日礼物是？"——客户每个选项都折射出当下最真实的焦虑与渴望，系统做到精准一一对应、实时响应需求并推荐服务，同时提示有寿险规划师全程支持：

| 客户表达期望（话题） | 系统对应服务推荐 |
|---|---|
| 关注宝宝健康 | 360Health 专家 / 特需门诊预约协调（含陪诊） |
| 计划家庭旅行 | VIP 全球礼宾服务（定制旅程） |
| 重视财务规划 | 保单检视服务（家庭保障更清晰） |
| 注重情绪健康 | 360Health 心理咨询（呵护爸妈情绪） |

**亮点 3：每一份礼遇赠送都是「同频」的成长支持（儿科医生 1v1 在线）**
0-3 岁家庭最重视健康，不同成长阶段的父母关注点各有侧重。儿科医生提供 1v1 在线支持，精准解决个性化问题：

- **1 岁+**：吃南瓜泥起红疹是不是过敏？流鼻涕影响打疫苗吗？长得慢是不是缺钙？（宝妈）；独自带娃辅食添加有困惑？疫苗接种有疑问？（宝爸）
- **2 岁+**：如何顺利度过"Terrible Two"？快速安抚宝宝小脾气？湿疹痱子怎么防？宝宝哭闹不止 / 容易摔倒怎么办？
- **3 岁+**：如何缓解分离焦虑？应对幼儿园常见病症？训练如厕？帮宝宝交朋友？发音不准怎么办？锻炼平衡能力？

### 5.2 代理人互动策略

**黄金 3 个月经营期**：关键在于把握好"宝宝生日前月、当月、次月"这 3 个月的经营窗口（礼遇发放后共 3 个月经营期）。

**客户旅程与触点**：

| 时间节点 | 公司推送 | 代理人互动 |
|---|---|---|
| 宝宝生日**前月月初** | 宝宝（被保人）进入 iAgent-Care Plus「生日客户名单」；互动工具：生日贺卡、保障视图 | — |
| 宝宝生日**当月 1 号** | 父母（投保人）进入 iAgent-Care Plus「关爱客户名单」 | 登录关爱名单 → 筛选"宝宝生日礼遇" → 点「去互动」提前送祝福 |
| 宝宝生日**当天** | 庆生信 / 微信推文 / 短信；生日抽奖提醒 | 基于客户动态（是否查看礼遇）及关心话题（如情绪健康）自然开展互动 |
| 宝宝生日**次月**（满 3 个月） | 礼遇满期 | 持续跟进，深化信赖 |

> **规则**：客户需在宝宝生日月结束前领取礼遇；领取后需在 **1 个月内激活**；激活后服务期为 **1 年**（3 次）。

**三个实战场景示例**：

**场景示例 1：客户尚未查看礼遇 → 转发海报破冰**
- 适用对象：状态为"客户未查看礼遇"的客户（如带红心的高加保潜力客户）。
- 动作：点击「去互动」→ 系统自动生成精美海报（"宝宝的生日礼遇来啦！扫码即领"）→ 一键微信转发。
- 话术核心逻辑：**先谈感情与痛点 → 再送服务与安心 → 最后才是业务机会**。用宝宝成长细节建立情感共鸣，用育儿痛点体现同频支持，把礼遇包装成"安心方案"自然送出，最后巧妙提及保单自带增值服务（如专家门诊预约），为后续加保埋下伏笔。

**场景示例 2：客户头像有"1"角标但未激活 → 转发海报提醒激活**
- 角标含义：客户有新动态（首次查看 / 领取礼遇后亮起，代理人互动后消失）。
- 动作：转发海报，扫码直达激活页面；结合客户感兴趣话题进一步推荐服务。
- 话术示例："宝宝就要 2 岁啦，您之前领的儿科电话医生服务，激活后就能随时咨询专家，快扫码激活吧！另外，我想帮您把现有保障权益和增值服务梳理一下，让家庭保障更清晰……"
- 关键：标签 = 客户真实意图（如客户曾选"为宝宝的热爱开启更多可能"→ 重视家庭财务规划）。

**场景示例 3：客户已激活礼遇 → 转发海报提醒使用，深度经营**
- 动作：点击「去互动」→ 分享海报 → 客户扫码直达服务使用界面。
- 话术核心逻辑：**先肯定客户行为建立信任 → 再用成长痛点引发共鸣 → 最后用"懂妈妈"的关怀提供情绪价值**。
- 示例（针对 #注重情绪健康 客户）："看到您激活儿科医生服务啦！3 岁宝宝正处'小叛逆期'，离开妈妈总是哭闹，如何缓解分离焦虑？我们有很受欢迎的心理咨询服务，能帮您舒缓情绪……"
- 核心逻辑：客户已激活 → 系统提示兴趣点（如心理咨询）→ 同理心话术切入 → 顺势介绍相关增值服务。实现从「送福利」到「真关心」的跨越。

**两个实战案例（话术宝典）**：

**案例 1：育儿更加注重高质量陪伴**
- 客户痛点：没时间陪、哄睡焦虑。
- 必做动作：点「去互动」转发海报 → 引导客户扫码找入口。
- 话术参考："小郁妈妈，提醒您喜马拉雅儿童 APP 的适龄故事能帮您解决哄娃'不知道讲什么'的难题。另外，若遇到孩子入园焦虑或情绪波动，我们还有 360Health 专家一对一心理咨询……"
- 转化思路：**→ 教育金**（客户关注陪伴质量，说明重视孩子未来成长，可顺势聊"为宝宝未来教育储备做准备"）。

**案例 2：育儿更加注重心理健康**
- 客户痛点：哭闹 / 不合群、带娃焦虑。
- 必做动作：点「去互动」转发海报 → 引导扫码找回服务入口 & 激活码。
- 话术参考："小都爸爸，'儿童情绪解读'能帮您读懂孩子行为背后的信号。同时大人带娃也累，我们还有 360Health 同样支持成人心理疏导；如需，更有就医绿通帮您预约三甲医院专家……"
- 转化思路：**→ 重疾 / 医疗类产品**（从心理关怀延伸至健康兜底）。

## 八、iAgent「三心」提示 & AI 加保模型

> 数据已验证：**拥有"三心"的客户，加保率是其他客户的 4.3 倍！** 把同样时间花在"三心"客户身上，产出可能是普通客户的 4.3 倍，请务必优先跟进。

**"三心"含义**：iAgent 客户卡上的三颗红心标记，代表**加保潜力评分前 20%** 的高潜力加保客户。

**AI 加保潜力模型（2026 年新升级）**：
```
加保潜力 = 客户粘性（被保人个数 / 成为客户时长等）
         × 客户态度（健康举措 / 养老规划等）
         × 客户互动（Care Plus / 微店等）
         → AI 加保潜力评分
```
- 建模平台：微软 Azure Machine Learning，选取最优模型 **LightGBM**。
- 数据维度：AI 基于客户 **70+ 个维度**数据综合分析给出综合评分。
- 数据验证：加保率基于有孩家庭 Phase 2（3-15 岁），加保时间 2026/1/1-4/30。

**两类高价值客户画像（重点服务对象）**：

| 特质 | 名称 | 特征 |
|---|---|---|
| 特质一：高加保动机 | **保障需求"觉醒者"** | 理念成熟、需求明确：已为多位家人配置保障、认同家庭整体规划；"都会天使"等长险多年连续续保；积极参与 Care Plus 等健康互动、关注长期健康与养老；过去 1 年参与微店活动、填写问卷，互动高频 |
| 特质二：高加保条件 | **最佳服务"接收者"** | 信任深厚、易触达易沟通：与公司及代理人建立强连接，沟通渠道畅通、信任感强；合作时间长，信任基础牢固 |

> **策略**：将有限精力优先投入这两类高价值客户（"三心"客户）。

## 九、iAgent-Care Plus 操作路径

**核心入口**：iAgent-Care Plus 关爱客户名单

**标准动作**：
1. **筛选客户**：在关爱名单中筛选"已参与客户""代理人未互动"等标签，掌握客户动态。
2. **去互动**：点击客户卡 →「去互动」→ 系统自动生成互动海报。
3. **微信转发**：一键转发给客户，客户扫码即可直达专属 H5 页（领取 / 激活 / 使用），通过身份识别进入。
4. **看客户卡**：点头像查看客户详情、保障、现有服务权益；客户卡展示「客户动态」+「话题标签」，是沟通的切入点。

**客户卡关键信息**：
- **动态**：客户是否查看 / 领取 / 激活礼遇，是否有新动态角标。
- **话题**：客户在 H5 互动中表达的需求（如 #注重情绪健康、#重视财务规划）。
- **角标**：客户首次查看 / 领取礼遇后亮起，代理人互动后消失。

> **Tips**：增值服务工具箱中有丰富的服务介绍和服务案例，可前往 iAgent-增值服务页面查看。

## 十、常见问题 FAQ（三大活动）

### 10.1 宝宝生日礼遇 FAQ

**Q1：哪些客户符合活动条件？**
面向 1-3 周岁生日的宝宝，宝宝需是 1 年期及以上有效保单的被保险人 / 受益人，沟通对象为宝宝的投保人。代理人可在 iAgent-Care Plus 关爱名单查看下月、本月、上月过生日的宝宝及其投保人信息。
- 举例：宝宝在 11、23、35 个月大时进入名单，在 14、26、38 个月大时退出。

**Q2：客户的礼遇是什么？**
儿科电话医生服务，服务期 1 年，服务次数 3 次，由爱康健康科技集团提供。

**Q3：客户如何领取礼遇？**
1. 查收方式：公司通过定向推送（邮件、微信服务通知等）发送专属 H5 链接；代理人也可通过活动海报转发（iAgent-Care Plus 关爱名单 → 去互动 → 微信转发）。
2. 领取流程：链接进入专属 H5 → 完成简单问答互动 → 领取儿科电话医生服务。
3. 领取时间：客户需在**宝宝生日当月截止前**领取，逾期失效。

**Q4：客户领取礼遇后需要注意什么？**
- 激活有效期：领取后需在 **30 天内激活**，逾期无法激活。
- 服务期限：激活后服务期 1 年，服务次数 3 次。
- 特殊情况：宝宝有多位投保人，分别有 1 次礼遇可领取。

**Q5：如何保护客户个人信息？**
礼遇 H5 页面采用身份校验。已绑定微客服的客户支持无感跳转；未绑定的客户需输入姓名 + 证件号验证后进入。

**Q6：客户咨询时，代理人如何回应？**
转发活动海报请客户扫码进入专属页面领取 / 激活 / 使用；在关爱名单客户卡查看客户动态及时跟进；提醒客户保存海报（服务有效期 1 年，扫码即用）。路径：iAgent-Care Plus 关爱名单 → 去互动 → 微信转发。

**Q7：iAgent 客户卡的"话题"是什么？**
话题 = 客户在 H5 互动中表达的需求（详见第五章 5.3 标签体系表）。

**Q8：儿科电话医生服务细则**
由爱康健康科技集团提供。激活后服务期 = 实际激活日 + 365 天；服务时间早 8:00-晚 8:00（法定春节假期除外）；点击呼出电话即可发起服务。
