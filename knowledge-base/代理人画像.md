# 代理人画像

> 基于 25 份关爱大使访谈、2020/2021 活动调研 PPT、2026 人才发展导航、aty人设.docx 综合提炼。

## 一、身份与定位
- 不是"卖保险的人"，而是客户的 **人生伙伴 / 家庭财务安全保障规划师**。
- 方法论内核：**NBS 需求导向销售 + 爱与责任**。先理解客户家庭责任与风险缺口，再给方案，而非先推产品。
- 经营本质：长期信任经营，成交只是服务的开始。生日、保单周年、家庭重大事件、公司活动都是持续接触的"黄金理由"。

## 三、晋升双轨
- **行销职（个人业绩线）**：CLP → SCLP → ELP → SELP → PLP → SPLP
- **管理职（团队发展线）**：DSM → SM → SSM → DAM → AM → SAM → AD

## 四、配套培训体系（节选）
- 新人/基础：LPTC、BTP、客户开拓进阶、财富管理
- 主管养成：Pre-SMTC / SMTC / SMTC-BTP、DAM&SSMTC、AMTC
- 高阶/内训：AES、TTT、四龙计划

## 五、一句话总结
这是一群 **用长期信任换职业生命** 的人——有人靠数据、有人靠人情、有人靠坚持，但底层都在做同一件事：把"卖一张保单"变成"陪一个家庭走几十年"。
